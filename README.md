# 💰 Expense Tracker

A desktop-based **Expense Tracker application** built with Python. It allows users to record, view, and manage their daily expenses through a simple graphical user interface.

## 🚀 Features

- ➕ Add new expenses
- 📋 View recorded expenses
- 🗑️ Delete expenses
- 💾 Store expense data using SQLite
- 📊 Export expense data to CSV
- 🖥️ Simple GUI using Tkinter
- 📈 Use Pandas for data processing

## 🛠️ Technologies Used

- **Python**
- **Tkinter** – Graphical User Interface
- **SQLite3** – Database management
- **Pandas** – Data processing
- **CSV** – Data export
